# 🔥 Core Difference

| Prompt Engineering | Context Engineering |
|--------------------|--------------------|
| Focuses on writing instructions | Focuses on managing entire model input |
| Static or manual | Often dynamic and system-driven |
| Mostly text crafting | Includes memory, RAG, tools, data pipelines |
| Tactical | Architectural |
| Smaller scope | Bigger system-level scope |
